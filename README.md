# AI-Based Network Intrusion Detection System (NIDS)

## Overview

This project develops an AI-powered Network Intrusion Detection System (NIDS) capable of detecting malicious network traffic using Machine Learning algorithms.

The system analyzes network traffic, preprocesses the data, trains multiple ML models, compares their performance, and predicts whether network activity is normal or malicious.

---

## Objectives

- Detect network intrusions
- Compare multiple ML algorithms
- Select the best-performing model
- Provide a web-based prediction interface
- Generate evaluation reports

---

## Machine Learning Algorithms

- LightGBM
- CatBoost
- Extra Trees Classifier
- Histogram Gradient Boosting
- Passive Aggressive Classifier
- Multi-Layer Perceptron (MLP)
